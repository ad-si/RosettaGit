SEMAPRAX is an experimental pre-alpha systems programming language from
[Wavect GmbH](https://wavect.io/). Human-readable `.spx` source remains the
canonical Git representation, while a stable semantic graph is the preferred
interface for agents. Public declarations use persistent identities, and the
project documents deterministic projections and evidence-gated change routes.

The current compiler documents bounded native C11/Clang and WebAssembly Core
output lanes. SEMAPRAX is primarily implemented in Rust and released under the
Apache License 2.0.
